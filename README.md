Bez's Optics and Microscope Builder: BOMB

This is a program to help plan, lay out, understand and tweak optical tables when building microscope setups. Physical fidelity and ease of use are key. It's meant to augment actually sitting at an optical table and trying things, but in a digital environment.

It's 95% made by LLMs, so the code is more or less unreadable. It's somewhat a project in understanding how to scale up complexity to LLMs without them losing the thread of what's going on. 

Feel free to steal it and do whatever you want. After all the LLMs are stealing it already.

Some inspiration: 
https://www.pencilofrays.com/
https://phydemo.app/ray-optics/ (2D ray simulator, beautiful)
https://studio.oliveoptics.com/playground (3D ray simulator, even more beautiful but a bit buggy)
https://wavetracer.dev/ (non-local wave tracer, I cannot emphasize how many weeks I wasted trying to create a wave tracer instead of a ray tracer)
